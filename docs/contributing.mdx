- **Bugs and feature requests**: [GitHub Issues](https://github.com/IgorFilippov3/senlo/issues).
- **Questions and ideas**: [GitHub Discussions](https://github.com/IgorFilippov3/senlo/discussions).

## Editing these docs

These pages are MDX files in [`docs/`](https://github.com/IgorFilippov3/senlo/tree/main/docs) of the Senlo repository, rendered at [senlo.io/docs](https://senlo.io/docs).

- One page per file; the sidebar order is in each folder's `meta.json`.
- Link to other pages by relative file path (`../api/events.mdx`), so links work on GitHub and on the site.
- The API reference is generated from `docs/openapi.yaml`. Change the YAML together with the request schemas in `packages/core` when an endpoint changes.
- Mark behavior that differs between Senlo Cloud and self-hosted with a `<Callout type="info" title="Cloud only">` or `title="Self-hosted only"` block.

Open a pull request; a docs change needs no issue first.
